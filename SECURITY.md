# Security policy

## Supported versions

Security fixes are provided for the latest published version of the Recap Raven Obsidian plugin. Update to the newest release before reporting behavior that may already have been corrected.

## Report a vulnerability privately

Use GitHub's private [Report a vulnerability](https://github.com/RecapRaven/obsidian-recap-raven/security/advisories/new) form. Do not open a public issue for a suspected vulnerability.

Do not include API keys, authorization headers, SecretStorage values, private campaign material, or imported recap content. If a credential may have been exposed, revoke it immediately from the [Recap Raven API-key page](https://recapraven.com/account/api-keys) before reporting the issue.

Please include:

- the affected plugin version and Obsidian version;
- the operating system;
- a concise description of the impact;
- reproducible steps using synthetic data; and
- any suggested mitigation.

We review complete reports, investigate them, and coordinate remediation and disclosure with the reporter on a best-effort basis. We do not offer a response, remediation, or disclosure SLA or SLO. Please allow a reasonable remediation period before publishing details.

## Scope

This policy covers the code in this repository. For Recap Raven account, website, or API concerns that do not involve this plugin, use the security contact published by [Recap Raven](https://recapraven.com).
